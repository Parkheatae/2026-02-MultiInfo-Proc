# 2026-11-05 멀티미디어 정보처리

### 화소 표현 및 연산

- 2중 for 반복문은 연산 시간이 오래 걸리기 때문에, 가급적 지양
- lut (look up table)은 연산 시간이 for 반복문보다는 빠르지만, 특별한 경우 아니면 사용을 자제
- opencv의 add, subtract, numpy의 행렬 연산을 사용

### 영상 합성

- 단순 영상 합성인 경우 명암의 표현 범위를 넘어서기 때문에 가중치를 이용해서 합성
- 가중치의 합이 1인 경우, 원래 영상의 밝기를 유지, >1 경우 밝아지고, <1 어두워진다.
- float 와 uin8 연산에서 발생한 연산오차 발생 가능 -> addWeight를 사용해라

### 히스토그램

- 구간별로 (bin) 화소의 수를 계량해서 도수 분포로 표시
- 여러가지 방법이 있지만, 영상에 특화된 cv2.calcHist() 권장
- histogram은 matplotlib.pyplot 을 이용해서 bar 그래프 형식으로 출력
