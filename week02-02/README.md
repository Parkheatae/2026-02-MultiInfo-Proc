# 2026-09-10 멀티미디어 정보처리 학습 내용

- 파이썬 기본 자료형 학습

  - 정수형(`int`)
  - 실수형(`float`)
  - 복소수형(`complex`)
  - 문자열(`str`)
  - 불리언(`bool`)
  - 자료형 변환: `int()`, `float()`
- 논리 연산자 학습

  - `and` 연산
  - `or` 연산
  - 논리 연산 결과 확인
- 컬렉션 자료형 학습

  - 리스트(`list`)
  - 튜플(`tuple`)
  - 세트(`set`)
  - 딕셔너리(`dict`)
- 리스트 주요 기능 실습

  - 값 추가: `append()`, `extend()`, `insert()`
  - 값 삭제: `remove()`, `pop()`, `clear()`
  - 값 검색: `index()`, `count()`
  - 순서 변경: `reverse()`, `sort()`
  - 리스트 요소 수정
  - 리스트 복사와 참조 차이
    - `my_list2 = my_list`
    - `my_list.copy()`
- 튜플 학습

  - 여러 값을 하나로 묶는 자료형
  - 리스트와 달리 수정이 어려운 자료형
  - 튜플 간 연결 연산
- 세트 학습

  - 중복된 값을 허용하지 않음
  - 값 추가: `add()`
  - 교집합: `&`
  - 합집합: `|`
  - 차집합: `-`
  - 대칭 차집합: `^`
- 딕셔너리 학습

  - 키와 값의 쌍으로 데이터 저장
  - `keys()`, `values()`, `items()` 사용
- 문자열과 줄 나누기

  - `\n`을 이용한 줄바꿈
  - 역슬래시(`\`)를 이용한 코드 줄 나누기
  - 삼중 따옴표를 이용한 여러 줄 문자열 작성
- 변수 활용

  - 변수에 값 대입
  - 임시 변수를 이용한 값 교환
  - 다중 할당을 이용한 값 교환
  - 튜플 패킹과 언패킹
  - `_`를 이용한 사용하지 않는 값 처리
