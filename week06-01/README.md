# 2026-10-06 수업 참여

## 켑스트럼, 리프터링 (liftering), 멜-스케일, 멜-필터뱅크, MFCC

- **켑스트럼** : 스펙트럼에 로그함수를 적용하여 IFFT를 실행

  - 스펙트럼에서 포락 (envelope)과 고조파 (harmonics)를 분리
    - 포락 : 모음을 판별
    - 고조파 : 기본 주파수를 분석
- **리프터링**

  - 켑스트럼에서 대역을 분리할 때 사용하는 개념
  - 필터링과 유사하나 큐프렌스에서 적용
- **멜-스케일**

  - 사람의 청각 특성을 반영하여 켑스트럼에 적용
- **멜-필터뱅크**

  - **필터뱅크** : 주파수 분석에서 매개변수 수를 줄이기 위해 주파수 영역을 균등하게 분할하여 에너지를 계산
  - **멜-필터뱅크** : 균등한 주파수 분할 대신 멜-스케일을 적용
- **MFCC**

  - 멜-필터뱅크의 에너지에 로그를 취한 후, DCT를 적용하여 켑스트럼 계수를 구함
