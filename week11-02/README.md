# 2026-11-12 멀티미디어정보처리

- 회선에 개념 학습 (mask 적용하여 화소값을 변경)
  - blur, sharpening
    - blur : 동일한 값을 적용하여 영상을 부드럽게 함
    - sharpening : 화소간의 차이를 크게 함
- 윤관선 검출
  - 1차 미분 : 인접한 화소의 차이를 반영
    - Roberts 적용 : 잡음에 민감
    - Prewitt : Roberts 의 단점을 보완
    - Sobel : Prewitt에서 가운데 수직이나 수평을 강조
      - 가장 많이 사용한 1차 미분 방법
  - 2차 미분
    - Laplacian
    - 1차 미분을 다시 적용 (1차 미분 값에 1차 미분 또 적용)
    - 1차 미분의 단점 보완 : 에지가 너무 많이 생김
      - 잡음에 민감하는 또 다른 단점이 생김 ==> LoG, DoG 적용
