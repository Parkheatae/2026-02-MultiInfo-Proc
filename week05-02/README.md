3. 스펙트로그램을 그림
   * 스펙트럼과 스펙트로그램의 차이를 숙지
     * 스펙트럼 : 특정 시간의 주파수 특성을 표현
     * 스펙트로그램 : 시간의 변화에 따른 주파수 특성을 표현 (스펙트럼 * 반복)

* 윈도우/프레임 크기에 따른 주파수 특성 확인
* * 광대역 : 윈도우 크기가 작다.
    * 시간축의 분해능이 높고, 주파수측의 분해능이 낮다
  * 협대역 : 윈도우 크기가 넓다.
    * 시간축의 분해능이 낮고, 주파수측의 분해능이 높다

4. 유성음과 무성음의 파형 특성 및 주파수 특성을 확인
