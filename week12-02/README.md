# 2026-11-19 멀티미디어 정보처리 수업

- 모폴로지 연산 (형태학)
  - 침식 : 작은 잡음 제거, 객체의 경계를 축소
  - 팽창 : 객체 내부를 소거, 잡음은 확대
  - 침식-팽창 : 열림 연산
    - 잡음이 반복적으로 제거되면서 객체가 소실
  - 팽창-침식 : 닫힘 연산
    - 객체의 크기는 유지가 되나, 객체 내부의 채움으로 확대
- 자동차 번호판 추출
  - 마스크를 번호판 특성에 맞게 설정
  - 닫힘 연산을 반복
  - 이미지 처리 과정
    - 명암 영상 -> 블러링 -> 소벨 미분적용 -> 이진화 -> 닫힘 연산
- 사상
  - 순방향 사상 : 원본 영상의 좌표를 목적 영상의 좌표로 변환
    - 축소 : 화소의 중복
    - 확대 : 홀(hole) 이 발견
  - 역방향 사상 : 목적 영상의 좌표로부터 원본 연상의 좌표를 계산
    - 확대 : 계단 현상이 관찰 -> 보간 (interpolation)이 필요
