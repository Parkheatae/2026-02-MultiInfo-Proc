# 2026-11-10 멀티미디어정보처리 수업

- 색상 히스토그램
  - 강의 후반부에서 학습한 HSV 색상공간 이용
- 히스토그램
  - 기존의 방식 `calcHist()` 함수 이용
- 히스토그램을 이용한 영상 화질 개선
  - 스트레칭: 최소값과 최대값을 이용하여 화질 개선 (히스토그램 늘림)
  - 평활화: 히스토그램의 누적 분포를 개선
    - 최소값과 최대값이 영상의 색 범위에 가까워서 분포를 이용
- 색상공간
  - RGB: 모니터, 광
  - CMY: 인쇄 (감산)
  - HSI: 사람의 시각
  - Ycbr: 압축
  - YUV: 방송
- HSV를 이용한 색 검출
  - 상위 값은 `THRESHOLD_TOZERO_INV` 이용
  - 하위 값은 `THRESHOLD_BINARY` 이용
